Projects generated by **Wails New** use a modern, minimal frontend stack designed
for **fast iteration**, **clear structure**, and **long-term maintainability**.

The stack is intentionally close to standard web tooling to avoid lock-in.

## Overview

The frontend stack consists of:

- **Svelte 5** — UI framework
- **Vite** — development server and bundler
- **Tailwind CSS v4** — utility-first styling
- **TypeScript or JavaScript** — selectable at generation time

Each component is chosen for simplicity and performance.

---

## Svelte 5

Svelte 5 is used as the UI framework.

Why Svelte:

- Compile-time reactivity
- Minimal runtime
- No virtual DOM
- Clear mental model

Svelte components are written using the modern Svelte 5 syntax and tooling.

---

## Vite

Vite powers:

- Local development server
- Hot module replacement (HMR)
- Production builds

Benefits:

- Near-instant startup
- Fast rebuilds
- Native ES module workflow

In development mode (`wails dev`), Vite runs alongside the Wails backend.

---

## Tailwind CSS v4

Tailwind CSS v4 is preconfigured and ready to use.

Features:

- Utility-first styling
- No runtime dependency
- Consistent design primitives
- Easy theming

The configuration is minimal and can be extended freely.

---

## TypeScript vs JavaScript

During scaffolding, you can choose between:

- **JavaScript** — simpler setup, fewer tools
- **TypeScript** — stronger guarantees, better editor support

This choice affects:

- Frontend source files
- Vite configuration
- Tooling defaults

Both options produce equivalent project structures.

---

## Asset Handling

Vite handles:

- Static assets
- CSS processing
- Module resolution

You can use standard web conventions for importing assets in Svelte components.

---

## Design Goals

The frontend stack aims to be:

- Explicit
- Familiar to web developers
- Easy to replace or extend
- Free of hidden abstractions

You should be able to upgrade or swap parts without fighting the tooling.
